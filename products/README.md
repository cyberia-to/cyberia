# products

the goals cyberia keeps alive, from [[org]]: one page per product, the page is the door of the product's repository, and every claim on it carries a dot — 🟢 measured · 🟡 target · 🔴 mock. a product is delivered when every dot is green; the dots are set by the counter from `audit/` pages, never by hand.
