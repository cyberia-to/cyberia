# processes

the recurring ways cyberia works, from [[org]]: each is a skill of the composite kind, written as a graph of nodes. every node holds a loop — produce, check, correct, repeat until green — and the check is written first, as something a program can evaluate. between nodes travel only pages and cyberlinks. the vocabulary of every graph is the same four node kinds: a splitter cuts work into units, a worker does one unit in its own context, a code node transforms without judgment, a gate opens or returns.

| process | turns | into | human at |
|---|---|---|---|
| [[deliver]] | an accepted product page | a released product whose claims a simulated user has passed | the irreversible lane |
| [[research]] | a question | a page of knowledge with evidence | none |
| [[listen]] | what real users do and say | tasks and changes to product pages | none |
| [[market]] | a released product | people who come, understand and join | the voice of the state |
| [[operate]] | machines and domains | a running, observed, recoverable estate | the irreversible lane |
| [[govern]] | a proposal about the charter | a verdict, and every page it touches re-accepted | every verdict |
| [[steward]] | sigma — what the state holds | budgets that open or close lanes | spending above a threshold |

three rules hold in every process. a return carries five fields — unit, verdict, reason, evidence, scope — and goes to the node that produced the unit, never to the batch; three returns of one unit mean the plan is wrong, and the plan goes back to its splitter. an accepted result goes back as a constraint into the brief of the splitter that cut it, so the next run starts where this one ended. a gate opens on the cost of being wrong, never on confidence: a reversible and contained change opens on green checks alone; a reversible but wide change opens on green checks and a clean trajectory; an irreversible change opens only by a human's hand.
