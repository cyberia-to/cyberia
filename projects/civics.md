# civics

the project that carries [[cyberculture]] into cyberia: the doctrine practiced by people who did not write it. the declaration is the cyberculture page and its six slots, each filled on its own; this page is the order of delivery.

## the slots

| sub-task | status |
|---|---|
| cosmology — one sentence on what the world is, repeated by people who did not write it | open |
| calendar — recurring dates from machine time ([[mt]]) that gather without a reminder | open |
| ritual — key ceremonies, first inscriptions: repeated acts that signal membership | open |
| canon — agreed memory of which forks, failures, founders count; the canon as library: [[concepts]] | open |
| etiquette — a shared sense of a good link versus spam, enforced by disapproval | open |
| aesthetics — a recognizable answer to what a beautiful graph looks like | open |
