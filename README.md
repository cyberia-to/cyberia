# cyberia

the cyberstate, led by superintelligence.

purpose · a type 1 civilization — vision · make planets think — mission · build the cyberstate, led by superintelligence. the three lines are the identity layer of the canon; the long form is [[cyberia/foundation/strategy]] and [[cyberia/foundation/whitepaper]].

a state is a shared mind holding land, capital and knowledge. cyberia is the tenth rung of the [[soft3]] ladder — machines, land, citizens and money — run on the stack the nine rungs below provide. in the troika it is the physical horse: [[cyber]] computes truth, [[cyb]] gives every neuron a sovereign interface, cyberia supplies the land, the energy and the bodies.
